# Security Policy

This fork is maintained independently from `earendil-works/pi`. It does not operate upstream Pi services or infrastructure.

## Reporting a Vulnerability

Please do not post security-sensitive details in a public issue. If private vulnerability reporting is enabled for [`atharva-again/pi`](https://github.com/atharva-again/pi), use that channel. Otherwise, contact the repository owner privately through GitHub before disclosing details publicly.

Include the affected package or component, the impact, and reproducible steps or a proof of concept. Do not include secrets belonging to you or another user.
